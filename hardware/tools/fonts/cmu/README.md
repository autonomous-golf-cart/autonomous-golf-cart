# CMU Serif

CMU Serif Roman, Bold, and Italic are bundled for reproducible catalog images.
The fonts are licensed under the [SIL Open Font License 1.1](OFL.txt).

The TTF files preserve the CMU Serif family and glyphs, decoded from the existing
CMU Serif WOFF2 assets used by the reference design. No font conversion package
is needed to regenerate the catalog.

Upstream font package: [Computer Modern Unicode on CTAN](https://ctan.org/pkg/cm-unicode).
The accompanying license is from that package's `doc/OFL.txt`.
